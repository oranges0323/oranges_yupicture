云端协同AI图库
项目介绍：
我的企业级云端协同AI图库平台基于Spring Boot和Vue 3构建，重点解决个人和团队对图片管理的需求，提供高效、安全、易用的图库服务。
主要功能：
● 图片编辑、上传与分享：用户可以方便地上传、编辑和分享图片，支持多种图片格式，包括JPG、PNG、JPEG和WEBP。
● AI扩图：平台接入AI扩图技术，为用户提供丰富的AI体验，提升用户体验和互动性。
● 颜色搜索：用户可以通过颜色搜索相关的图片，提供更加个性化的搜索体验。
● 批量处理：用户可以批量上传、编辑和删除图片，提高工作效率。
● 批量抓图：用户可以从网页中批量抓取图片，方便快捷。
● 以图搜图：用户可以通过图片搜索相关的图片，提供更加直观的搜索体验。
● 团队协同：用户可以创建团队空间，邀请和管理团队成员，团队内共享图片并实时协同编辑图片，提高团队协作效率。
● 空间管理：用户可以创建个人空间或团队空间，便于管理自己的图库，并进行扫码分享，批量编辑，空间分析，实时监控存储情况。
技术选型：
● 后端：采用 Spring Boot、MySQL、MyBatis-Plus、MyBatisX、Redis、Caffeine、Jsoup、COS（腾讯云对象存储）、Sa-Token、WebSocket、Disruptor、AI扩图模型 和 JUC（Java Util Concurrent）技术，实现了快速构建、稳定的关系型数据库、增强的ORM功能、分布式和本地缓存、网页数据抓取、安全高效的云存储、简洁易用的权限认证、双向通信、高性能队列和并发编程。
● 前端：采用 Vue 3、Vite、Ant Design Vue、Axios、Pinia、ECharts、Cropper 和 WebSocket 技术，实现了组件化开发、快速构建、丰富的UI组件、简化HTTP请求、轻量级的状态管理、强大的数据可视化、灵活的图片裁切和实时数据交互。
通过以上技术选型，构建了一个高效、稳定且具有良好用户体验的企业级协同 AI 图库平台，帮助用户更好地管理和利用其图片资源。
